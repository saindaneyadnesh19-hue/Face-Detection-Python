# Face Detection and Recognition System

A Python-based Face Detection and Recognition System using OpenCV and Tkinter. The system can detect faces through a webcam, train a face recognition model, and identify registered faces in real time.

## Features

- Real-time face detection using webcam
- Face dataset collection
- Face recognition using LBPH algorithm
- Real-time face identification
- Unknown face detection
- Simple graphical user interface using Tkinter
- Face count display

## Technologies Used

- Python
- OpenCV
- NumPy
- Tkinter
- Haar Cascade Classifier
- LBPH Face Recognizer

## Project Files

- `main.py` – Real-time face detection and face counting
- `dataset.py` – Captures face images for the dataset
- `train.py` – Trains the face recognition model
- `recognize.py` – Performs real-time face recognition
- `app.py` – Graphical user interface for the system

## How to Run

1. Install the required libraries:

```bash
pip install opencv-python==4.10.0.84
pip install numpy
2.Run the face detection system:
python main.py
3.To create a face dataset:
python dataset.py
4.Train the recognition model:
python train.py
5.Start face recognition:
python recognize.py
6.To use the graphical interface:
python app.py
